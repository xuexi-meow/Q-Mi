# Q-Mi 运行控制台升级设计

日期：2026-11-11
状态：范围与总体方案已确认，待书面设计复核

## 1. 目标与范围

用户确认选择“完整控制台”，并特别强调美化必须落实。本次将现有 WebUI
升级为日常管理和排查 Agent 行为的运行控制台，保留已有能力与部署方式。

交付范围：

- 重做导航、布局、排版、图标、配色及移动端适配，提供明暗主题。
- 新增真实的只读上下文检查器、运行状态和后台任务查看。
- 整理消息与事件查看流程，改进搜索、滚动和筛选。
- 完善配置表单、变更预览、未保存保护及异步状态。
- 保留情绪、笔记、定时器、唤醒、提示词编辑和 QQ 管理。

不包含：直接修改或清空运行上下文、暂停/打断 Agent、新增审批执行通道、
请求回放、费用定价、替换模型或改变自主活动规则。

## 2. 保留的约束

- 继续使用 Go HTTP server、go:embed 和已有 Alpine.js，无 Node 构建依赖。
- 浏览器资源随程序内嵌，不依赖 CDN；图标采用本地 Lucide 资源。
- 所有运行数据与写操作继续置于 Bearer token 鉴权后。
- 保留单账号共享上下文和自主串行活动循环，不引入按群独立 Agent。
- 不修改用户的人格正文、真实连接密钥、群聊存档或无关工作区改动。
- 自动化验证不调用真实模型、不执行真实 QQ 操作。

## 3. 视觉与信息架构

### 3.1 整体风格

这是工作控制台，不做营销首页或装饰性大横幅。

- 深色主题使用中性炭灰底与清晰的表面层级，避免整页深蓝。
- 浅色主题使用冷白和中性灰；两种主题均使用青绿作为主要操作色。
- 蓝色用于来源/链接，琥珀色用于处理中/警告，红色用于失败/危险。
- 色彩不是唯一状态依据，同时提供图标与文字。
- 正文 14px，辅助文字 12px，页面标题 22px；不随视口宽度缩放字号。
- 字距为 0，控件与重复条目圆角不超过 8px。
- 页面分区采用无框布局、分隔线和全宽条带，不将分区堆成嵌套卡片。
- 刷新、复制、展开、删除和主题等操作采用 Lucide 图标，并提供可访问名称
  与悬停提示；明确的提交命令可使用图标加文字。
- 为图标按钮、状态计数和工具栏定义稳定尺寸，加载状态不引起跳动。

### 3.2 导航

桌面使用固定左侧导航，主区域宽度不再限制为 960px。导航包含：

1. 运行概览
2. 当前上下文
3. 消息记录
4. 活动日志
5. Agent 管理
6. QQ 管理
7. 配置

侧栏底部包含主题切换与退出登录。主区域顶部显示页面名、连接状态及当前
页面操作。导航支持 hash 深链接与刷新恢复。

手机宽度下导航变为抽屉，列表/详情视图可返回，不将所有栏目挤在一行。
表格在小屏改成可读的条目或受控滚动区域，页面本身不得横向溢出。

### 3.3 页面内容

- 概览：运行阶段、NapCat 状态、累计请求/输入输出/缓存命中、上下文预算
  概况、按候选用量、近期错误和到上下文/日志的入口。
- 当前上下文：摘要指标、来源与类型筛选、搜索、消息列表和按需详情。
- 消息记录：会话搜索、会话列表、聊天详情、限定当前会话或全局的搜索。
- 活动日志：类型/来源/关键词筛选、暂停跟随、展开长内容、复制单条。
- Agent 管理：状态与笔记、定时器、手动唤醒、提示词编辑、后台任务查看。
- QQ 管理：好友/群/成员查看与独立的高级动作区。
- 配置：模型、行为与上下文、工具板块分栏；需重启字段只读展示。

## 4. 运行状态与快照架构

### 4.1 并发边界

`conversation` 目前由账号 worker 持有，HTTP handler 不直接读取它，也不在
整个模型请求期间等待 `runMu`。

新增独立的观测快照组件：

- worker 在请求前、响应与工具回执合并后、压缩完成后及活动结束时发布快照。
- 先构造不可变的展示 DTO，再通过独立的短锁替换快照引用。
- 阶段信息在开始请求、执行工具、压缩及结束时更新。
- HTTP 只读取已发布快照，不调用 builder、压缩器或模型。
- 空闲仍保留最后工作快照，明确显示更新时间；进程重启后为空。
- 快照中各条消息和工具调用必须深复制，调用方不能修改运行数据。
- 收件箱数量通过已有收件箱锁独立读取，不写进聊天内容。

快照来源明确区分 `request`（实际行动请求输入）和 `working`（响应/工具结果
合并后的工作记录）。展示的请求时间与工作快照时间不能混用。摘要请求状态
单独标识，不把摘要专用提示词当作日常工作上下文。

### 4.2 运行状态

状态包括：尚未初始化、空闲、准备上下文、请求模型、执行工具、压缩上下文、
错误。Agent 配置未启用应单独返回 disabled，而不是伪装为空闲。

包含当前/最近候选名、模型名、档位、轮次、活动开始时间、更新时间、
待处理消息数。失败切换候选时及时更新实际候选；结束后不再显示“正在请求”。
后台任务可能在 Agent 空闲时继续执行，两者状态分开显示。

### 4.3 上下文展示数据

每条记录包含：

- 快照版本内索引、API role、分类（提示词/输入/状态/摘要/输出/工具回执）。
- 可可靠提取时提供 chat_type、chat_id、message_id、user_id、origin。
- 文本、工具名与参数、tool_call_id、多模态图片数量。
- 原已存在且需随请求回传的 reasoning_content 单独折叠，不混成 QQ 发言。
- 对应文本/工具/图片/推理的估算占用；总计使用现有估算函数。

不能可靠提取来源时标记未知，不从历史摘要或自由文本猜出一个群。
图片仅展示数量和占位标识，不传 base64 或自动加载原图 URL。
工具 schema 作为单独的工具定义分类按需查看，其占用计入总预算。

token 全部标为“估算”，不得声称与提供商 tokenizer 或计费输入精确相同。
展示预算、消息数、工具数、压缩次数及最近请求的实际 usage（若有），
明确估算值与提供商返回值的不同。

## 5. API 与数据限制

新增受现有鉴权保护的只读接口：

| 路由 | 方法 | 用途 |
|---|---|---|
| /api/runtime | GET | 运行阶段、快照指标、队列数量 |
| /api/context | GET | 带版本号的上下文分页与筛选 |
| /api/context/message | GET | 指定版本与索引的单条详情 |
| /api/tasks | GET | 后台任务的有界列表与结果预览 |

上下文列表默认每页 40 条，上限 100 条；先按类型/会话/关键词过滤再分页。
列表正文预览最多 1000 个 Unicode 字符；详情单个文本字段最多 64000 字符，
截断必须返回标记与原始长度，不做静默截断。

详情引用的版本已被替换时返回 409，前端提示刷新，不能用旧索引读新消息。
复制与 JSON 下载只包含界面获取的展示数据；有截断时保留截断标记，不标成
完整原始请求。导出不提供模型连接配置或请求鉴权头。

任务列表最多最近 100 项，结果与错误有界展示；第一版不提供任务取消按钮，
避免暗示现有工具闭包一定能中止外部副作用。

新接口只接受 GET，其他方法返回 405。运行数据响应使用
`Cache-Control: no-store`。空列表返回 `[]` 而非 `null`。

## 6. 安全与隐私

- 上下文含群聊、私聊和提示词，仅授权管理员可看；不发布到静态资源。
- 新 DTO 不读取 API key/token 配置，不包含 HTTP 鉴权头。
- 对工具参数与结果中的结构化敏感字段（api_key、token、authorization、
  password、secret）遮蔽展示；自由文本可能含用户主动提供的隐私，不能
  承诺自动识别所有秘密，也不改变模型实际上下文。
- 所有用户内容用文本绑定渲染，不用 innerHTML；测试覆盖 HTML 注入。
- 登录失败显示明确状态，首次登录后导航和刷新均正确启动。
- 退出登录清除保存的令牌、上下文、事件、消息及配置等浏览器内存数据。
- 危险 QQ 动作切换后确认框总是未勾选；必须由用户显式确认才能执行。
- 自动化与预览环境使用假数据/假接口，不启动生产机器人。

## 7. 交互逻辑

### 7.1 刷新与异步

- 仅当前可见页面轮询；标签页隐藏时暂停，恢复可见后补刷新。
- 请求未结束时不重叠发起同类轮询，切换页面清理旧定时器。
- 最新数据加载失败保留旧内容，同时标记失败和最后成功时间。
- 暂停跟随允许阅读较早日志，不强制滚到底部；新事件只更新计数。
- 写操作提交中禁用重复提交，成功/失败有明确反馈。
- 查看控制台不调用模型连通性测试；测试模型仅由显式点击触发。

### 7.2 消息记录

加载更早消息后维持阅读位置，初次进入会话才滚到底部。搜索结果跳转时围绕
命中消息加载并突出显示；若缺少定位接口，则增加只读定位查询，不假装
已经跳转到只包含最新消息的页面。切换会话时忽略过期请求的返回值。

显示会话类型与 ID、发送者、时间、消息 ID；@ 和引用从已有 segments 提取，
引用缺失时明确显示未知，不根据名字猜测。群名/昵称尽量复用已获取数据，
不为展示单条消息反复调用 QQ。

### 7.3 编辑与配置

- 轮询及进入其他面板不能覆盖尚未保存的提示词或配置草稿。
- 离开编辑页/重新加载前有未保存提醒，浏览器关闭使用 beforeunload。
- 保存前展示字段变更并调用已有 validate 接口，确认后提交覆盖层。
- 失败保留草稿，成功更新基线。分区保存不覆盖其他分区的草稿。
- 模型候选的已有字段必须保留，不能丢弃 tool_choice、context_window、
  cooldown、weight 或环境变量配置；支持原有单模型档位写法。
- 密钥使用密码输入，显示脱敏值不意味着写入该脱敏字符串。
- 数值用 number/stepper，二元开关用 checkbox/toggle，模式用分段控件，
  选项集合用 select/menu，不用普通文字按钮伪装选择器。
- 提示词保存后的生效文案与 builder 实际热读行为一致，不再固定写“重启生效”。
- 提示词编辑接口按当前配置解析允许的 persona/guide 路径，仍拒绝任意路径。

## 8. 文件边界

- `agent/inspection.go`：观测 DTO、深复制、快照发布、分页过滤与展示脱敏。
- `agent/manager.go`、`agent/compaction.go`：只增加发布/阶段更新点。
- `agent/hooks.go`：导出只读查询，保持未启用时安全。
- `webui/inspection.go`：运行/上下文/任务 HTTP handler 与参数校验。
- `webui/webui.go`：接入路由，必要的消息定位与段元数据扩展。
- `webui/config.go`：配置与文件路径的必要接口修正。
- `webui/static/index.html`：页面语义结构与 Alpine 绑定。
- `webui/static/console.css`：主题、布局与响应式。
- `webui/static/console.js`：导航、请求、分页、编辑草稿与页面状态。
- `webui/static/lucide*`：本地图标资源与许可证。

不拆成多个前端框架或引入全局状态管理库。文件拆分以页面与请求职责为界，
避免继续把 CSS、HTML 和所有业务逻辑塞进同一个文件。

## 9. 验证与验收

后端测试覆盖：

- Agent 未启用、未初始化、空闲、请求中、完成和错误状态。
- 模型 HTTP 请求阻塞时，读取观测快照仍快速返回。
- 快照不可变、版本冲突、筛选分页、工具调用/回执配对、图片不泄漏。
- token 估算与工具 schema 占用、压缩标记、字段脱敏及截断说明。
- 新 API 的鉴权、方法、参数、空数据及禁止缓存。
- 当前消息定位、引用元数据和提示词配置路径读取/保存。

前端使用本地假 API 与 Playwright 验证：

- 1440x900、1024x768、390x844 的明暗主题截图与无横向溢出检查。
- 登录错误/成功/退出、刷新恢复导航、抽屉开关。
- 上下文筛选/详情/版本更新/复制与截断提示。
- 日志暂停跟随、旧消息加载阅读位置、搜索结果定位。
- 配置变更预览、校验失败保留草稿、未保存保护、重复提交拦截。
- 危险操作不自动确认、恶意消息按纯文本渲染。
- 无浏览器控制台错误、无未处理 Promise rejection，键盘聚焦可用。

最终运行 `go test ./... -count=1`、`go vet ./...`、`git diff --check`，
并提供独立预览地址。预览不使用真实连接密钥，不让测试操作触达 QQ。
运行控制台正式生效需要重新编译/重启，不能仅修改内嵌文件而声称已部署。
